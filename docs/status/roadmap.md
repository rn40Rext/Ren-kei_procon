## 2. マイルストーンに先行して着手すべき項目

**マイルストーンの順序より優先する項目があります。**

### ⚠️ 最優先: Storage Rules の全開放を閉じる — [#50](../../../issues/50)

`storage.rules` が現在 `allow read, write: if true` であり、**未認証の第三者が動画をアップロード・上書き・削除できます**。本格的な所有者ベース Rules は MVP Community（#40）ですが、**アプリを誰かに触らせる前に対処すべき**です。

最小限の対応（`match /{allPaths=**} { allow read, write: if request.auth != null; }` への変更だけでも未認証アクセスは防げます）を [#50](../../../issues/50) で先に入れ、本格実装は #40 で仕上げる二段構えとしています。

## 5. 進め方の提案

1. **着手前に B-1（ナビゲーション未登録）を直す** — AI 機能の開発で `Camera` / `Result` 画面を使うため
2. **Storage Rules の最低ラインを入れる** — 未認証アクセスを止める
3. **Prototype 1 を最優先** — 姿勢推定の方式が決まらないと AI 機能全体が進まない
4. **#22（Encoder 検証）を並行** — 他と独立しており、結果が出るまで時間がかかる。早く始めて早く判断する
5. **連機能（MVP Ren）は #26 から** — データ構造を固めないと管理者機能が着手できない
